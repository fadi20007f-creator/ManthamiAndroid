# منظّم مهامي — Android

مشروع Android Studio كامل للنسخة الأولى.

المزايا:
- واجهة رئيسية بمربعات للأقسام.
- فتح كل قسم وعرض مجموعة مهامه.
- إضافة مهمة.
- تحديد المهمة كمكتملة.
- حذف مهمة.
- حذف المهام المنجزة.
- إضافة أقسام جديدة.
- حفظ البيانات محلياً على الجهاز.
- واجهة عربية RTL.

فتح المشروع:
1. فك ضغط الملف.
2. افتح مجلد `ManthamiAndroid` في Android Studio.
3. انتظر Gradle Sync.
4. اختر Build > Build APK(s).
5. ستجد ملف APK داخل `app/build/outputs/apk/debug/`.

ملاحظة: المشروع يحتاج Android Studio واتصالاً بالإنترنت أول مرة لتنزيل Gradle/dependencies.
